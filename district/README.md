# 행정구역 지도 — 성남시 분당구

행정동·법정동 경계를 **여러 개 동시에** 띄워 보는 정적 페이지입니다.

네이버지도나 카카오맵에서 "수내1동" 을 검색하면 그 구역 하나만 보여 주고, 다른 구역을
보려면 다시 검색해야 합니다. 이 페이지는 수내1·2·3동을 한 화면에 서로 다른 색으로 함께
띄우고, 분당구 전체 범위도 같이 확인할 수 있게 만든 것입니다.

**공개 주소**: https://chaejwan.github.io/HDHR_CJW/district/

로컬에서 보려면 저장소 루트에서 정적 서버를 띄웁니다. (`file://` 로 열면 데이터 파일을
불러오지 못합니다.)

```bash
npx http-server -p 8080 .
# http://localhost:8080/district/
```

## 기능

- **행정동 / 법정동 체계 전환** — 같은 "수내" 라도 어느 체계로 볼지 명시적으로 고릅니다
- **다중 선택** — 목록 체크박스나 지도 클릭으로 여러 구역을 동시에 선택
- **초성 검색** — `수내` 는 물론 `ㅅㄴ` 으로도 찾습니다
- **구 전체 보기** — 내부 경계선 없는 분당구 외곽선을 따로 표시
- **면적 표시** — 구역별 면적과 선택한 구역들의 합계 면적
- **선택만 보기** — 고른 구역만 남기고 나머지를 숨김
- **URL 공유** — 선택 상태가 주소창에 남아 링크 하나로 같은 화면을 재현합니다
- 배경지도 밝게 / 어둡게 / 없음, 다크 모드 대응, 좁은 화면 대응

### 색상

인접한 구역끼리 같은 색이 되지 않도록 빌드 단계에서 그래프 컬러링으로 색을 배정합니다.
분당구 22개 행정동은 4색으로 구분됩니다.

### 구역 이름 위치

중심점(centroid)은 U자형이나 초승달형 구역에서 폴리곤 바깥에 찍힙니다.
내접원 중심(pole of inaccessibility)을 계산해 항상 구역 안쪽에 이름이 놓이게 했습니다.

## 데이터

| 체계 | 상태 | 원천 |
|---|---|---|
| 행정동 (22개) | 들어 있음 | 통계청 SGIS 기반 [vuski/admdongkor](https://github.com/vuski/admdongkor) ver20260701, CC BY 4.0 |
| 법정동 | **비어 있음 — 준비 필요** | VWorld 또는 주소기반산업지원서비스 |

법정동 경계는 행정동을 합쳐서 만들 수 없습니다(두 체계는 N:M 관계). 별도 원천이 필요하고,
받는 방법은 [`tools/README.md`](tools/README.md) 에 정리해 두었습니다. 준비되면 법정동 탭이
자동으로 켜집니다.

## 구조

```
district/
  index.html        화면
  style.css
  app.js            지도·목록·검색·URL 상태
  vendor/           MapLibre GL JS 5.24.0 (BSD-3-Clause)
  data/             빌드 결과 — 직접 손대지 않습니다
    manifest.json   구역 목록·면적·라벨 위치·색상 인덱스
    bundang.hjd.geojson
    bundang.outline.geojson
  tools/
    build_data.py   원천 → data/ 변환
    README.md       데이터 준비 절차
```

MapLibre 는 CDN 대신 저장소에 넣어 두었습니다. 외부 CDN 이 죽어도 페이지가 뜨고,
배경지도를 "없음" 으로 두면 네트워크 없이도 경계가 그려집니다.

## 다른 지역

`tools/build_data.py` 의 `TARGET` 을 바꾸면 다른 시군구로 옮길 수 있습니다.
용인시처럼 일반구(수지구·처인구·기흥구)가 있는 곳은 구별로 만든 뒤 합치면 시 전체가 되는데,
구가 시를 빈틈없이 나누므로 단순 합집합으로 정확히 맞아떨어집니다.
자세한 내용은 [`tools/README.md`](tools/README.md) 를 보세요.
