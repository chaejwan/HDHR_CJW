확인할 사이트

사이트를 처음 등록하면 첫 확인 때의 목록을 기준으로 저장하고(알림 없음), 그 다음 확인부터 새로 올라온 글만 메일로 알려 줍니다. 목록이 잡히지 않으면 확인 방식을 브라우저 렌더링으로 바꿔 보세요.

확인 주기

자주 쓰는 값

확인은 GitHub Actions 가 30분마다 깨어나 담당합니다. 여기서 정한 주기가 지난 사이트만 실제로 확인하므로 30분보다 짧게 잡는 것은 의미가 없습니다. GitHub 예약 실행은 혼잡하면 건너뛰거나 늦어질 수 있어, 실제 확인 간격은 정한 값보다 조금 길어질 수 있습니다.

알림 이메일

이 저장소가 공개(public)라면 여기 적은 주소도 공개됩니다. 주소를 감추고 싶으면 이 칸을 비우고 저장소 Secrets 에 JOBMON_RECIPIENTS 로 넣으세요 (설정보다 우선합니다).

보내는 메일 계정 (SMTP) 설정
비밀번호는 이 화면에 넣지 않습니다. 저장소 Settings → Secrets and variables → Actions 에서 JOBMON_SMTP_PASSWORD 로 저장하세요. (Gmail 은 앱 비밀번호) 서버·아이디·보내는 주소도 감추고 싶다면 JOBMON_SMTP_HOST, JOBMON_SMTP_USER, JOBMON_SMTP_FROM 시크릿을 쓰면 이 설정보다 우선합니다.

저장 권한 (GitHub 토큰)

설정을 저장하거나 ‘지금 확인 실행’ 을 누르려면 본인 GitHub 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 어디로도 전송되지 않습니다 (GitHub API 호출에만 사용).

토큰 만드는 방법
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 에서 이 저장소만 선택
  3. Permissions → Repository permissions 에서 Contents: Read and write, Actions: Read and write 허용
  4. 만들어진 토큰을 위 칸에 붙여 넣고 토큰 저장

토큰 없이 쓰려면 아래 설정 JSON 복사 를 눌러 저장소의 job-monitor/config.json 을 GitHub 화면에서 직접 수정해도 됩니다.
